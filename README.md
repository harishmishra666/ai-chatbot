# 🤖 AI Chatbot

A simple Python-based chatbot that interacts with users through the command line and responds to predefined questions and conversations.

## 📌 About the Project

This project is a beginner-friendly chatbot developed using **Python**. It demonstrates basic chatbot logic, user input processing, conditional statements, and conversational responses.

The project is designed as a foundation for building more advanced **AI and LLM-powered chatbots** in the future.

## ✨ Features

* 💬 Interactive conversation through the terminal
* 👋 Greeting responses
* 🤖 Basic AI-related questions
* 🐍 Python-related responses
* 🧠 Machine Learning information
* ✨ Generative AI information
* ⚙️ Automation information
* 🏫 Sri Ram Swaroop related responses
* 🚪 Exit commands using `bye`, `exit`, and `quit`
* 🎯 Beginner-friendly implementation
* 🔄 Easy to extend with new responses

## 🛠️ Technologies Used

* **Python 3**
* Functions
* Conditional Statements
* While Loops
* String Processing
* User Input Handling

bash

## 💻 Example

text
🤖 AI Chatbot
Type 'bye' to exit.

You: hello
Bot: Hello! How can I help you?

You: what is ai
Bot: AI stands for Artificial Intelligence. It enables machines to perform tasks that normally require human intelligence.

You: python
Bot: Python is a popular programming language used in AI, automation, data science, and software development.

You: bye
Bot: Goodbye! Have a great day 👋
```
