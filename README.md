# 🤖 AI Chatbot

A simple Python-based chatbot that interacts with users through the command line and responds to predefined questions and conversations.

## 📌 About the Project

This project is a beginner-friendly chatbot developed using **Python**. It demonstrates basic chatbot logic, user input processing, conditional statements, and conversational responses.

The project is designed as a foundation for building more advanced **AI and LLM-powered chatbots** in the future.

## ✨ Features

* 💬 Interactive conversation through the terminal
* 👋 Greeting responses
* 🤖 Basic AI-related questions
* 🐍 Built completely with Python
* ⚡ Lightweight and easy to run
* 🎯 Beginner-friendly implementation
* 🔄 Easy to extend with new responses

## 🛠️ Technologies Used

* **Python 3**
* Conditional Statements
* Functions
* User Input Processing

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/harishmishra666/ai-chatbot.git
```

### 2. Open the project folder

```bash
cd ai-chatbot
```

### 3. Run the chatbot

```bash
python chatbot.py
```

## 💻 Example

```text
🤖 AI Chatbot
```
